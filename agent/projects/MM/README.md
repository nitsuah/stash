# MoneyMakers (MM)

Small, low-effort earning projects. Each one should take about a day to set up or overlap with shared setup.

- Tracking: Neon project `moneymakers` (`divine-surf-90579532`): tables `projects`, `money_events`, view `project_pnl` (one `projects` row per project)
- Human vs. agent split: [human-vs-agent.md](human-vs-agent.md)
- Idea catalog: `agent/projects/MM/earning-ideas.md`

## Rules

- Money moves, account signups, KYC, tax IDs, passwords, and ad spend are human-only.
- Agents draft. Humans publish or send. Every public post, listing, or email needs your go-ahead.
- Each project gets a kill rule before it starts. Log it in the `projects` row.
- Money events (revenue, cost, hours) go into `money_events`.
