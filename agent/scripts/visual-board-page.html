How the board is scored

Actions PRs is the repo setting that lets workflows open pull requests; screenshot and diagram CI need it. Promo manifest is promo/spots.json. Screenshots and Diagrams are done when CI regenerates them and partial when they're only committed. Features linked counts the features with something to show that appear in a spot or screenshot (80% counts as done). Spots published compares published spots with all spots.

Each repo's score counts done as 1 and partial as ½. Today's pick is the first gap among tier I repos, walking the columns left to right, so the cheapest unblocking fix comes first.
