# Security roadmap

Program tracker: nitsuah/stash#302 (inventory) - this file is the plan of record. Never put secrets, tokens, or exploit payloads in issues, PRs, or docs.

## Principles

- Plan before fixing; outputs are generated by scripts so they can be re-run as repos change.
- Sensitive findings go to private draft security advisories; only hardening and docs work is filed publicly.
- Fix classes once (shared controls), then roll the control out per repo by tier.

## Tiers

| tier | meaning | repos |
|---|---|---|
| T0 | hosted/remote + credentials, money, identity, or code execution | ats-fill, fire, imps-runner, motor-pool, skyview, vigil |
| T1 | authenticated apps, integrations, dev servers with keys | bb-mcp, darkmoon, deployer, gcp, gods-eye-view, kryptos, nitsuah-io, stash, vhs |
| T2 | local tools, static sites, demos (must not bind publicly or leak secrets) | 9router, avatar, brag, farm-3j, games, osrs, windirstat-mcp |

## Phases

0. **Critical response (immediate)** - the highest-impact findings are filed as private advisories and contained right away; plan sign-off governs the broader remediation, never emergency handling.
1. **Fix-once controls** - shared helpers and lint rules for the cross-repo themes below.
2. **Tiered remediation** - per-repo work in tier order, one small tracked item each.
3. **API keys & rotation** - one standard key-management design (generate/rotate/revoke from the GUI, encrypted at rest), themed per app.
4. **Branding** - deterministic logo/icon generation per repo and OAuth consent-screen updates (console changes verified, not assumed).

## Cross-repo themes

| theme | standard control |
|---|---|
| authn-authz-gap | Deny-by-default middleware + per-route authz matrix + a test per route |
| unbounded-input-or-body | fetchCapped(): streamed byte budget + timeout; cancel on overflow |
| sensitive-data-exposure | Response DTO allowlists and redaction; no raw config in responses |
| redos-regex | Linear scanners or RE2 for untrusted text; length caps; regexp lint |
| path-containment-symlink | safeResolve(root, p): path.relative + realpath containment, O_NOFOLLOW, exclusive temp files |
| ssrf-redirect | safeFetch(): resolve+block private ranges per hop, manual redirects, scheme allowlist |
| xss-html-injection | No raw innerHTML templates; escape helper or DOM APIs; schema-validate imports; strict CSP |
| oauth-flow-binding | One OAuth helper: per-attempt random state/nonce + PKCE, expiring, single-use, bound to session |
| unbounded-compute | Schema/range validation at ingress (zod); loop and work budgets; worker timeouts |
| proxy-policy-bypass | Single proxyAwareFetch() choke point; lint that forbids raw fetch/http2 |
| secret-exposure-argv-or-logs | Secrets via env/stdin/keychain only, never argv or logs; redact in log layer |
| fallback-or-demo-credential | Fail-closed startup config validator; no default secrets or demo logins in prod paths |
| cors-network-exposure | Bind 127.0.0.1 by default; Host/Origin allowlist; no wildcard CORS |
| tls-verify-disabled | Never set rejectUnauthorized:false; support CA bundle option instead |
| llm-agent-trust | Least-privilege tools, human approval for egress/writes, no auto-loaded model-chosen URLs |
| shell-command-injection | execFile/spawn with argv arrays, shell disabled; no string-built commands |
| log-injection | Structured JSON logging; never interpolate caller text into log lines |
| browser-security-disabled | No --disable-web-security in any launcher; one shared launcher helper |
| code-exec-parser | Data-only frontmatter/doc parsing (YAML/JSON only); ban document-selected engines |
| csv-formula-injection | csvCell(): neutralize = + - @ tab CR prefixes before quoting |
| prototype-pollution | Map or Object.create(null); hasOwn checks |
