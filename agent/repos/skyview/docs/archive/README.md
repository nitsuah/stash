These are dated historical records. They are kept on purpose, but nobody maintains
them, and they describe the project as it was on the dates they carry. Don't follow
any instructions in them: file paths, `config.js` flags, and commands have
changed since.

| File | What it records | Current source of truth |
|------|-----------------|--------------------------|
| `PROJECT_STATUS.md` | Project status snapshot as of 2025-12-13, from before the refactor (`client-portal.html` at the repo root, no `platform/` SPA) | `docs/FEATURES.md`, `docs/ROADMAP.md`, `docs/CHANGELOG.md` |
| `SESSION_SUMMARY.md` | Summary of the 2025-12-13 WebP optimization and performance monitoring work session | `docs/WEBP_OPTIMIZATION.md`, `docs/PERFORMANCE_CHECKLIST.md` |
| `WEBP_IMPLEMENTATION.md` | "What was built" summary of the WebP feature | `docs/WEBP_OPTIMIZATION.md` |

On 2026-09-24 (F-20260923-02) we deleted the archived how-to docs `MANUAL_SETUP.md`,
`CONFIG_README.md`, `QUICKSTART.md` and `QUICK_REFERENCE.md`. Every still-accurate
step they had is already covered by the live docs, and the rest had gone stale. They
are still in git history if you need them.

For current setup, start at `docs/GETTING_STARTED.md` (marketing site, CMS,
config) and `docs/FINAL_SETUP.md` (marketplace platform), or read
`docs/OWNER_GUIDE.md` for the non-technical walkthrough.
