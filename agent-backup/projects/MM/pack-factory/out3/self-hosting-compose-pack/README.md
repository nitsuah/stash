# Self-Hosting Docker Compose Pack

Ten ready-to-run stacks. Each folder has `docker-compose.yml`, `.env.example` (copy to `.env`) and a README.

| Stack | What it is |
|---|---|
| umami | Privacy-friendly web analytics |
| uptime-kuma | Self-hosted uptime monitoring |
| listmonk | Newsletter and mailing lists |
| nextcloud | Private file sync and sharing |
| gitea | Self-hosted Git service |
| grocy | Household or shop inventory |
| photoprism | Private photo library |
| vaultwarden | Password manager server (Bitwarden-compatible) |
| n8n | Workflow automation |
| ntfy | Push notifications to your phone |

Requires Docker. These are starting points, not hardened production setups: use HTTPS, strong secrets, firewalls and backups. Personal and commercial use. Do not resell or redistribute the files themselves.
