Notes:

- **bb-mcp / sharp — new this week, live exposure.** Both `brand/package.json` and the duplicate `docs/brag/brand/package.json` pin `sharp": "^0.33.5"`, and both lockfiles resolve the actual install to exactly `0.33.5` — below the libheif RCE fix (`0.35.4`, GHSA-rgj7-g3m4-5g8c) that `nitsuah-io` and `skyview` already carry at `^0.35.4`/`^0.35.5`. Unlike this week's other findings, this one isn't just a declared-floor gap: the resolved install itself is in the vulnerable range, so it's rated CRITICAL rather than HIGH.
- **stash / sequelize — still unaddressed, 3rd report running.** First flagged 2026-10-01 (floor `^6.32.0` inside the vulnerable range 6.0.0-beta.1–<6.37.8 for a JSON-column-cast SQL injection, CVE-2026-30951). `stash` was unchanged for the 2026-10-08 report, so it carried forward untouched; this week `backend/express/package.json` was recreated from scratch in commit `a229e11` (2026-10-06 daily-brief) with the identical vulnerable `^6.32.0` pin and still no committed lockfile, so the resolved version can't be confirmed either way.
- **motor-pool / @modelcontextprotocol/sdk — still unaddressed, 2nd report running.** Same floor-vs-resolved gap flagged 2026-10-08: `tools/content-gen` and `tools/website` both still declare `^1.12.0` (vulnerable range for three stacked SDK advisories, widest being GHSA-345p-7cg4-v4c7, fixed 1.26.0), while both lockfiles resolve to `1.29.0` (patched). No live exposure today, but the floor hasn't moved.
- **motor-pool / axios — new this week.** `tools/content-gen/package.json` declares `axios": "^1.7.2"`, inside the range for several 2026 axios advisories (prototype pollution CVE-2026-44495/GHSA-3g43-6gmg-66jw, and a high-severity gadget vulnerability CVE-2026-42035/GHSA-6chq-wfr3-2hj9), both resolved by 1.16.1. The lockfile resolves the actual install to `1.17.0` (patched), so this is the same floor-vs-resolved pattern as the SDK finding above, not live exposure. `motor-pool/dashboard` and `bb-mcp` both declare `axios": "^1.20.0"`, already above the fix — unaffected.
